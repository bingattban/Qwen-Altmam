# ADR-0001 — One offline application; stable route identifiers and protected history
Status: owner-approved architecture constraints, implementation evidence remains phase-specific
Date: 2026-10-25

**Decision.** Preserve the single Windows desktop WPF + locally mapped WebView2 architecture, SQLCipher encrypted SQLite database with random per-installation key sealed by Windows DPAPI, and the original 00–15 phases. Four top-level post-login destinations: الرئيسية، التمام الشهري، الإدارة، الإعدادات. First-run setup and login precede them.

Use immutable PersonId, SiteId, StatusId, UserId in domain and storage while displaying historically effective names and the textual personnel number. Source-of-truth route identifiers are screen_001..screen_019 and screen_021..screen_070; screen_020 is retired. Never repurpose screen_020. screen_025 is the only unified Report; screen_026 its export; screen_070 is Add Person embedded under Edit Names. Maintain a single roster PersonId on verified return and preserve original audit evidence and temporal intervals.

**Security.** SQLCipher must reject wrong keys and missing native encryption. No universal embedded password. Founding GeneralAdmin exists once and is independent of personnel forever; subsequent users are active-roster-linked. All sensitive commands must enforce C# RBAC, 300s server-validated inactivity and audit snapshots, not only hidden UI.

**Safety and delivery.** Migrations use a transactional forward-only schema runner and require a verified encrypted rescue backup before upgrading an existing database. Artifacts are delivered via feature PR: parallel Core and Release; within Release full tests before Portable/Installer; same SHA and both-success are prerequisites to merge.

**Trade-offs / outstanding acceptance.** DPAPI alone is not portable across Windows machines; a separately password-protected recovery package belongs to Phase 12. Clean offline machine user tests belong to 13–15. A record's identity changing during a month may require an owner decision about header presentation, without changing effective-dated historical facts.
