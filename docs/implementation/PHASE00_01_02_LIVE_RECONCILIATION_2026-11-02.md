## المرحلة 02 — SQLCipher / ترحيل المخطط / ثبات الأدلة

|---|---|---|

| ترحيل قاعدة قديمة | صورة إنقاذ SQLCipher قابلة للفتح والتحقق **قبل** الترحيل وإيقاف الترحيل إذا تعذر حفظها | مختبر في CI |
| اكتشاف العبث عند إعادة فتح قاعدة حديثة | اختبار فشل أولاً ثم فحص `VerifyRecordedHashes` في `InitializeAsync` | **أضيف بهذه الدفعة؛ لا يدعى PASS حتى نجاح تشغيل Windows الجديد** |

| التبديل الفعلي لقاعدة البيانات | `RestoreDatabaseAtomically` معطل عمداً | **ممنوع تفعيله دون قرار المالك وقبول الأمان** |

**نتيجة 02:** المعمارية والتشفير والبيانات التاريخية منفذة، مع إضافة حماية جديدة لفحص
بصمة الترحيل عند فتح قاعدة موجودة أصلاً. يتبقى إثبات الترقية والتعافي الواقعي على Windows
نظيف وحالة قرص ممتلئ/انقطاع طاقة، ثم قرار منفصل بشأن تفعيل الاستعادة المدمرة.
